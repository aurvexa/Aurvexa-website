# Aurvexa Website

Static HTML/CSS/JavaScript version prepared for GitHub Pages.

## Deploy
1. Upload all files to the repository root.
2. Ensure `index.html` is in the root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save and wait for GitHub Pages to publish.

## Before publishing
- Replace the placeholder WhatsApp number in the footer.
- Replace sample testimonials with approved client testimonials.
- Add verified portfolio metrics only.
- Update contact email if needed.
